# 試合当日の運用手順

---

## 試合前（10分前まで）

### KYV47 側

1. 三脚に固定し、コート全体が入る画角にする
2. **充電ケーブルを挿す**（40分の 1080p 録画は電池を大きく使います）
3. EFK CAMERA を起動する
4. 本体画面の「試合前チェックリスト」を開いて、上から確認する
5. 画面に出ている **URL と PIN** を確認する

### 操作端末側

1. KYV47 と同じ Wi-Fi（またはテザリング）につなぐ
2. ブラウザで URL を開く（KYV47 の QR を読んでも可）
3. 初回だけ PIN を入力する
4. プレビューを「表示」にして画角を合わせる
5. **10秒だけ試し録りして、映像の向きが正しいか確認する**
   （上下が逆なら 設定 → 映像の向き を A ↔ B で切り替え）

### 確認しておくこと

- [ ] BATTERY が 50% 以上、または充電中
- [ ] FREE が「約60分」以上
- [ ] 警告が赤で出ていない
- [ ] `Google: emfrentekumamoto@gmail.com` になっている

## 試合中

1. 試合名を入力する（例：`GRTIA CUP U18 vs ○○高校`）
   - 入力欄の下に、実際に付く YouTube タイトルが出ます
2. 「🔴 録画開始」を押す
3. `REC ●` と経過時間が動き出したことを確認する
4. **あとは触らなくて大丈夫です**

### 途中で操作端末が使えなくなったら

**録画は続いています。あわてないでください。**

| 状況 | どうなるか |
|---|---|
| ブラウザを閉じた | 録画は継続。開き直せば「録画中 23:41」が復元される |
| 操作端末の電池が切れた | 録画は継続。別の端末から接続すれば操作できる |
| Wi-Fi が切れた | 録画は継続。つなぎ直せば操作できる |
| ルーターごと落ちた | 録画は継続。**KYV47 本体の「■ 録画停止」で止められる** |

### 警告が出たら

| 警告 | どうするか |
|---|---|
| ▲ 電池残量が少なくなっています | 充電ケーブルを挿す |
| ▲ 電池温度が40℃です | プレビューは自動停止済み。日陰へ移す。**録画は止めない** |
| ■ 電池温度が45℃です | 扇風機・日陰など。**それでも録画は止めない**（試合を失う方が損失が大きい） |
| ▲ 空き容量で録画できるのは約○分です | 未アップロードの動画がないか確認する |

## 試合後

1. 「■ 録画停止」を **1.5秒長押し** する（誤タップ防止）
2. 自動で「YouTubeへアップロード中 ○%」に変わる
3. 「✓ アップロード完了」と YouTube リンクが出れば終わりです
4. 元動画は自動で削除されます（削除されたら空き容量が戻ります）

### アップロードが始まらないとき

| 原因 | 対処 |
|---|---|
| 「Wi-Fi のときだけアップロード」が ON でテザリング接続 | そのまま持ち帰れば、自宅 Wi-Fi で自動アップロードされます |
| インターネットに出られない体育館 Wi-Fi | 同上。帰ってからで大丈夫です |
| Google アカウント未設定 | 本体でアカウントを選んでから「再アップロード」 |

**どの場合でも、元動画は消えません。** 「アップロード待ち」として保持されます。

### 「非公開でアップロードされています」と出たら

仕様です（SETUP_GOOGLE_CLOUD.md ステップ9）。
アップロード自体は成功しています。YouTube Studio から限定公開に変更してください。

## 持ち帰ってからやること

1. KYV47 を Wi-Fi につないで充電する
2. EFK CAMERA を起動する（アップロード待ちがあれば自動で再開します）
3. 操作画面（または本体画面）で「アップロード完了」になっているか確認する

---

## やってはいけないこと

- ❌ **「失敗（要確認）」と出ている動画を削除する**
  → YouTube に上がっていません。消すと二度と戻りません
- ❌ アプリのデータを消す／アンインストールする
  → アプリ専用領域に保存しているため、未アップロードの動画も一緒に消えます
- ❌ 録画中に設定を変更しようとする
  → できないようにしていますが、試さないでください
- ❌ 録画中にアプリを「強制停止」する
  → 書き込み中のファイルが再生できなくなる可能性があります

## 困ったときの早見表

| 症状 | 確認すること |
|---|---|
| 操作画面が開けない | KYV47 と同じ Wi-Fi か。URL の IP が変わっていないか（本体画面で確認） |
| PIN が通らない | 本体画面の PIN と一致しているか。5回失敗すると10分ロックされます |
| 「● 未接続」と出る | 録画は続いています。Wi-Fi を確認して待てば自動復帰します |
| プレビューが出ない | 端末の制約で使えない場合があります。**録画には影響しません** |
| 録画開始が押せない | 空き容量不足か、カメラの権限。警告欄を確認 |
| 動画が2本に分かれた | 60分を超えた可能性。自動継続した結果なので、2本とも上がります |
