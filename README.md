## EFK members（フットサルクラブ管理アプリ）

トップ / サテライト / U18 の選手・コーチのアカウント、権限、選手証、スケジュール・出欠、メッセージをまとめて管理するアプリの土台です。
「①アカウント・権限まわり」「②選手証の自動紐付け」「③スケジュール・出欠」「④メッセージ」まで実装済みです。

### セットアップ

`.env` に接続情報を用意してください（`.env.example` 参照）。

```bash
npm install
npx prisma migrate deploy
npm run dev
```

`http://localhost:3000` を開くと、まだ管理者が誰もいない場合は自動的に `/setup` に案内されます。
そこで最初の管理者アカウント（名前・カテゴリー・メール・パスワード）を作成してください。

### 本番公開（Vercel）

1. Vercelで、このGitHubリポジトリを新規プロジェクトとしてインポートする
2. プロジェクトの Storage タブから Blob ストアを作成し、このプロジェクトに接続する（`BLOB_READ_WRITE_TOKEN` が自動で設定される。選手証の写真の保存に使用）
3. プロジェクトの Settings → Environment Variables に以下を設定する

   | 変数名 | 値 |
   |---|---|
   | `DATABASE_URL` | Prisma PostgresなどのPostgres接続文字列 |
   | `JWT_SECRET` | ログインセッション用の秘密鍵（ランダムな長い文字列） |
   | `RESEND_API_KEY` | メール通知用（[resend.com](https://resend.com)で発行） |
   | `EMAIL_FROM` | 通知メールの送信元（例: `EFK members <onboarding@resend.dev>`） |
   | `NEXT_PUBLIC_APP_URL` | デプロイ後のURL（例: `https://xxxxx.vercel.app`）。通知メール本文のリンクに使用、未設定でも動作する |

4. Deployを実行する（ビルド時に `prisma migrate deploy` が自動で走り、データベースのテーブルが作成される）
5. デプロイ後のURLを開き、`/setup` から最初の管理者アカウントを作成する

以降は、このリポジトリにpushするたびにVercelが自動で再ビルド・再デプロイする（データは保持されたまま更新される）。

### できること

- 選手・コーチが自分でアカウント登録（名前・背番号・カテゴリー・ウェアサイズを入力、複数カテゴリー選択可）
- ウェアサイズ（シャツ・パンツ・ジャージ、大人男性用のS/M/L/XL/XXLからプルダウンで選択・任意）は登録時に選べるほか、マイページ（ダッシュボード）からいつでも変更できる
- 管理者は `/admin` からメンバー一覧（ウェアサイズ含む）を確認し、カテゴリー変更・管理者権限の付与/剥奪・アカウント手動追加ができる
- カテゴリーは以下の6種類、1人で複数持てる（`src/lib/categories.ts` で管理）
  - トップ選手 / トップコーチ
  - サテライト選手 / サテライトコーチ
  - U18(U15)選手 / U18コーチ
- `/admin/cards` からJFAの「登録選手一覧」PDF（トップ/サテライト/U18など、カテゴリーごと）をそのままアップロードすると、名簿内の名前・背番号・写真を読み取り登録済みメンバーと自動で紐付け。名前が一致しなかった選手は「要確認」に表示され、管理者が手動で選手を選んで紐付けられる。選手が増えたら更新した名簿PDFを再アップロードするだけでよい（背番号・写真も再アップロードのたびに最新化される）
- `/schedule` はカレンダー形式で予定を一覧できる。管理者・コーチ（`*_COACH`カテゴリーを持つユーザー）は `/schedule/new` から対象カテゴリーを選んで練習・試合予定を作成でき、予定はトップ（青）/サテライト（赤）/U18（緑）で色分けして表示される。自分のカテゴリー以外の予定も閲覧でき、対象カテゴリーの予定には出席/欠席/未定を回答できる（対象外の予定は閲覧のみ）。カレンダー・一覧の両方で、まだ出欠回答していない予定にはアンバー色のマーク・「未回答」バッジが付き、回答済みのものと一目で区別できる
- `/messages` でチャンネルごとのメッセージがやり取りできる。トップ/サテライト/U18/全体はデフォルトで用意され、そのカテゴリーのメンバーだけが見られる。`/messages/new` からSlackのように誰でもチャンネルを追加できる（対象カテゴリーを選ぶか、全員参加の「全体」チャンネルにするか選択）。チャンネルごとにメッセージは最新500件まで保持し、それを超えた分は投稿のたびに古いものから自動で削除される。チャンネル名は重複できない。自分が作成したチャンネル（管理者はどれでも）はチャンネル画面から削除できる。デフォルトのチャンネルは削除不可（アクセス権限はカテゴリーで自動判定されるため「退会」という概念はなく、見えるかどうかはカテゴリーの変更で調整する）
- ダッシュボードの「メッセージ」欄の下に「EFKアプリ」として関連アプリ（EFKtac / EFKtime / TACview）へのリンクを設置。アイコン・名前・説明付きでスマホでも見やすいカード表示、それぞれ新しいタブで開く（`src/lib/external-apps.ts` で管理）
- 新しい予定が作成された時・アクセスできるチャンネルに新着メッセージが投稿された時に、対象メンバーへメール通知を送信（Resend使用）。マイページの「新しい予定・メッセージをメールで通知する」チェックボックスでON/OFFを切り替え可能（デフォルトON）
- 管理者はマイページから、クラブの予定をGoogleカレンダー（など、URL購読に対応したカレンダーアプリ）に取り込める「購読用URL」を発行できる。Google側の複雑な連携設定は不要で、発行したURLをカレンダーアプリの「URLで追加」に貼り付けるだけ（プライバシーのため管理者のみが発行・利用可能）
- 出席率: 自分のカテゴリー対象の「過去の」予定のうち「出席」と回答した割合を自動計算。マイページ（自分の出席率）と管理者のメンバー一覧（全員分）で確認できる（`src/lib/attendance.ts`）
- スマホのホーム画面に追加可能（PWA）。ブラウザの「ホーム画面に追加」からアイコン付きでインストールでき、ブラウザのアドレスバーなしで開ける（`src/app/manifest.ts`）

### 技術構成

- Next.js (App Router) + TypeScript + Tailwind CSS
- Prisma + PostgreSQL（`prisma/schema.prisma`。Prisma Postgresなど、どのPostgresでも可）
- 認証は自前実装（bcryptjsでパスワードハッシュ化、joseでJWTセッションcookie）
- 選手証: pdfjs-distでJFA名簿PDFのテキスト層と埋め込み画像を直接抽出（OCR不要、名前は完全一致で誤読なし）、写真の整形はsharp
- アップロード画像（選手証の写真）はVercel Blobに保存（`@vercel/blob`）。ローカルディスクには保存しないため、Vercelのようなサーバーレス環境でも再デプロイでデータが消えない
- メール通知: Resend（`RESEND_API_KEY`, `EMAIL_FROM` を `.env` に設定。本番URLへのリンクを本文に含めたい場合は `NEXT_PUBLIC_APP_URL` も設定）。送信失敗は予定作成・メッセージ投稿自体には影響しない
