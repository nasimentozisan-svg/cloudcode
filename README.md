## EFK members（フットサルクラブ管理アプリ）

トップ / サテライト / U18 の選手・コーチのアカウント、権限、選手証をまとめて管理するアプリの土台です。
実装済みは「①アカウント・権限まわり」「②選手証の自動紐付け」です（スケジュール・メッセージは今後追加予定）。

### セットアップ

```bash
npm install
npx prisma migrate deploy
npm run dev
```

`http://localhost:3000` を開くと、まだ管理者が誰もいない場合は自動的に `/setup` に案内されます。
そこで最初の管理者アカウント（名前・カテゴリー・メール・パスワード）を作成してください。

### できること

- 選手・コーチが自分でアカウント登録（名前・背番号・カテゴリーを入力、複数カテゴリー選択可）
- 管理者は `/admin` からメンバー一覧を確認し、カテゴリー変更・管理者権限の付与/剥奪・アカウント手動追加ができる
- カテゴリーは以下の6種類、1人で複数持てる（`src/lib/categories.ts` で管理）
  - トップ選手 / トップコーチ
  - サテライト選手 / サテライトコーチ
  - U18(U15)選手 / U18コーチ
- `/admin/cards` からJFAの「登録選手一覧」PDF（トップ/サテライト/U18など、カテゴリーごと）をそのままアップロードすると、名簿内の名前・背番号・写真を読み取り登録済みメンバーと自動で紐付け。名前が一致しなかった選手は「要確認」に表示され、管理者が手動で選手を選んで紐付けられる。選手が増えたら更新した名簿PDFを再アップロードするだけでよい（背番号・写真も再アップロードのたびに最新化される）

### 技術構成

- Next.js (App Router) + TypeScript + Tailwind CSS
- Prisma + SQLite（`prisma/schema.prisma`）
- 認証は自前実装（bcryptjsでパスワードハッシュ化、joseでJWTセッションcookie）
- 選手証: pdfjs-distでJFA名簿PDFのテキスト層と埋め込み画像を直接抽出（OCR不要、名前は完全一致で誤読なし）、写真の整形はsharp
- アップロード画像は `uploads/`（gitignore対象、`public/` の外）に保存し、`/api/cards/[...path]` から配信（キャッシュされる静的配信を避けるため）
